# Group6-BudgetTracker-System

Budget Tracker System

System Description

The Budget Tracker System is a Python-based application designed to help users manage their daily income and expenses. The system allows users to add, view, update, and delete transactions while calculating the current balance.

---

Features (CRUD)

Create
•Add Transaction

Read
• View Transactions

 Update
• Update Transaction

Delete
• Delete Transaction

Additional Features
• View Balance
• File Handling
• Exception Handling

Data Fields
Each transaction contains the following information:

- Transaction ID
- Date
- Transaction Type (Income/Expense)
- Category
- Amount
- Description

Instructions on How to Run the System

Requirements

 • Python 3 installed on your computer

Steps

1. Download or clone the project repository.
2. Open the project folder.
3. Open a terminal or command prompt.
4. Navigate to the project directory.
5. Run the following command:

python main.py

6. Follow the menu options displayed on the screen.

---

Sample Menu

1. Add Transaction
2. View Transactions
3. Update Transaction
4. Delete Transaction
5. View Balance
6. Exit
